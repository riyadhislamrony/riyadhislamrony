### <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f44b/512.gif" width="28" align="center" /> About Me

I'm **Rony Hossain** (`@riyadhislamrony`), a self-taught software & automation developer from **Bangladesh** 🇧🇩. Most of my time goes into designing high-speed **Telegram bots**, resilient **MTProto file-streaming & auto-forwarding systems**, and clean **CLI/VPS automation tools** powered by Python and Docker.

Lately, I've been diving deep into how systems work under the hood—picking up **C, C++, and Rust**, and experimenting with binary & low-level fundamentals. I value software that is fast, minimal, and works reliably without fuss.

* <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/26a1/512.gif" width="18" align="center" /> **Core Focus:** Python, Pyrofork / Pyrogram (MTProto), `asyncio`, `aiohttp`, FFmpeg & MongoDB
* <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f6e0_fe0f/512.gif" width="18" align="center" /> **Infrastructure:** Docker Containers, Linux VPS Administration & Cloud Deployment
* <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f331/512.gif" width="18" align="center" /> **Currently Learning:** Rust, C/C++, JavaScript & Low-Level Binary Architecture
