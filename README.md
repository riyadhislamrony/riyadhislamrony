### <img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f44b/512.gif" width="26" /> About Me

I'm **Rony Hossain** (`@riyadhislamrony`), a self-taught developer from **Bangladesh** 🇧🇩. Most of my time goes into designing high-speed **Telegram bots**, resilient **MTProto file-streaming & auto-forwarding systems**, and clean **CLI/VPS automation tools** powered by Python and Docker.

Lately, I've been going deeper into how systems work under the hood—picking up **C, C++, and Rust**, and experimenting with binary & low-level fundamentals. I like tools that do one thing and work reliably without fuss.

* ⚡ **Core Focus:** Python, Pyrofork / Pyrogram (MTProto), `asyncio`, `aiohttp`, FFmpeg & MongoDB
* 🛠️ **Infrastructure:** Docker Containers, Linux VPS Administration & Cloud Deployment
* 🌱 **Currently Learning:** Rust, C, C++, JavaScript & Low-Level Binary Architecture
* 📢 **Updates & Bots:** [Riyadh's Bot Channel (@riyadhsbot)](https://t.me/riyadhsbot)
